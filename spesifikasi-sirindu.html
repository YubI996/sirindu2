Bagian 2

Fitur Utama

Manajemen Data Anak

  • CRUD data dasar anak (nama, NIK, tanggal lahir)
  • Jenis kelamin & alamat lengkap
  • Hierarki: Kecamatan → Kelurahan → RT
  • Relasi ke Puskesmas dan Posyandu

Data Periodik (DataAnak)

  • Pencatatan berat badan & tinggi badan
  • Perhitungan Z-Score otomatis (WHO)
  • IMT/U, BB/U, TB/U, BB/TB
  • Klasifikasi status gizi

Imunisasi

  • Pencatatan data imunisasi per anak
  • Riwayat imunisasi lengkap

Ekspor Data

  • Export Excel individual anak
  • Export Excel data massal
  • Export PDF (DomPDF)
  • Format laporan terstruktur

Konfigurasi Environment (.env)

.env — Konfigurasi Production
# ── Aplikasi ────────────────────────────────
APP_NAME=Sirindu
APP_ENV=production          # ganti dari local
APP_KEY=base64:xxx          # php artisan key:generate
APP_DEBUG=false             # WAJIB false di production
APP_URL=https://domain.anda

# ── Database ─────────────────────────────────
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sirindu
DB_USERNAME=<db_user>
DB_PASSWORD=<db_password>

# ── Session & Cache ───────────────────────────
SESSION_DRIVER=file          # ganti redis untuk performa
CACHE_DRIVER=file            # ganti redis untuk performa
SESSION_LIFETIME=120         # menit
QUEUE_CONNECTION=sync

# ── Log ──────────────────────────────────────
LOG_CHANNEL=stack
LOG_LEVEL=error              # error saja di production
Bagian 10

Langkah Setup di Server Baru

Terminal — Urutan Perintah Setup
# 1. Install dependencies
composer install --optimize-autoloader --no-dev
npm install && npm run build

# 2. Konfigurasi environment
cp .env.example .env
php artisan key:generate

# 3. Jalankan migrasi & seeder
php artisan migrate
php artisan db:seed

# 4. Optimasi cache production
php artisan config:cache
php artisan route:cache
php artisan view:cache

# 5. Set permission folder
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache
💡 Rekomendasi Production: Gunakan Redis untuk SESSION_DRIVER dan CACHE_DRIVER jika aplikasi diakses oleh banyak pengguna secara bersamaan. Tambahkan queue worker (php artisan queue:work) jika ada proses background yang diperlukan.
