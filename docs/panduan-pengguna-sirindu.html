Pendahuluan

Tentang SIRINDU, cara masuk, dan navigasi dasar

Apa itu SIRINDU?

SIRINDU (Sistem Informasi Anak Rindu) adalah aplikasi web yang dikembangkan oleh Diskominfo Kota Bontang untuk mendukung Dinas Kesehatan dalam mengelola data kesehatan anak secara terpadu. Aplikasi ini mencakup:

  • Pencatatan data identitas anak (0–6 tahun)
  • Pemantauan pertumbuhan berkala (berat badan, tinggi badan, lingkar kepala)
  • Penghitungan status gizi otomatis menggunakan standar WHO (Z-Score)
  • Pencatatan dan monitoring riwayat imunisasi
  • Surveilans epidemiologi penyakit menular (PD3I dan lainnya)
  • Ekspor dan impor data massal dalam format CSV/Excel
ℹ️
SIRINDU digunakan oleh petugas Puskesmas, Posyandu, dan Dinas Kesehatan Kota Bontang. Setiap pengguna memiliki akses sesuai peran yang diberikan oleh Super Admin.

Cara Login

  1. 1
    Buka browser Akses alamat aplikasi SIRINDU yang diberikan oleh administrator sistem.
  2. 2
    Masukkan kredensial Isi kolom Email dan Password yang telah diberikan oleh Super Admin.
  3. 3
    Klik Masuk Sistem akan mengarahkan Anda ke halaman Dashboard sesuai peran (Admin).
⚠️
Jika login gagal, pastikan Caps Lock tidak aktif dan hubungi Super Admin jika password terlupa.

Menu PD3I — Surveilans Epidemiologi

Pelaporan dan pemantauan kasus penyakit menular prioritas

Dashboard PD3I

Sidebar → PD3I → Dashboard PD3I

Dashboard PD3I menyajikan ringkasan visual semua kasus surveilans yang tercatat, memudahkan petugas dan pengambil keputusan untuk memantau situasi epidemiologi kota.

Konten Dashboard

  • Kartu Statistik: Total kasus, kasus aktif, sembuh, meninggal
  • Grafik Tren: Jumlah kasus per bulan (6–12 bulan terakhir)
  • Distribusi per Penyakit: Campak, Difteri, AFP, Pertusis, dsb.
  • Distribusi per Wilayah: Kasus per kecamatan
  • Tabel Kasus Terbaru: 10 kasus paling baru

Daftar Kasus Surveilans

Sidebar → PD3I → Daftar Kasus

Tabel lengkap semua kasus surveilans yang pernah dilaporkan, dengan fitur pencarian dan filter multi-kriteria.

Filter yang Tersedia

  • Jenis penyakit (campak, difteri, AFP, pertusis, tetanus neonatorum, dsb.)
  • Status kasus (Suspek / Probable / Konfirmasi / Discarded)
  • Kondisi akhir (Sembuh / Meninggal / Dalam Perawatan)
  • Rentang tanggal onset
  • Wilayah (kecamatan/kelurahan)

Cara Export CSV (Data Individual)

  1. 1
    Pilih filter yang diinginkan (bulan, kelurahan, antigen, status)
  2. 2
    Periksa preview — pastikan data yang tampil sesuai
  3. 3
    Klik tombol "Export CSV" di pojok kanan atas. File CSV akan langsung terunduh.

Cara Export Agregat Excel (Per Kelurahan)

Bagian Export Agregat per Kelurahan menghasilkan laporan rekap per kelurahan, dikelompokkan per vaksin dan kelompok (IDL/IBL/ISL).

  1. 1
    Pilih Bulan dari dropdown
  2. 2
    Pilih Tahun yang ingin diekspor
  3. 3
    Klik "Export Agregat Excel" — file Excel (.xlsx) akan terunduh
⚠️
Tombol Export Agregat Excel hanya aktif setelah Bulan dan Tahun dipilih. Jika tombol masih abu-abu, pastikan kedua filter sudah terisi.

Export Data Anak

Sidebar → Export Data → Export Anak

Unduh data dasar anak (identitas, wilayah, faskes) dalam format CSV atau Excel. Dapat difilter berdasarkan wilayah, posyandu, puskesmas, dan status gizi.

💡
File hasil export dapat digunakan sebagai template untuk diimport kembali setelah diubah, atau untuk keperluan pelaporan ke tingkat Kota/Provinsi.

Pemecahan Masalah Umum

MasalahSolusi
Login gagal / password salah Pastikan Caps Lock mati. Hubungi Super Admin untuk reset password.
NIK duplikat saat tambah anak Anak dengan NIK tersebut sudah terdaftar. Gunakan fitur Cari untuk menemukannya.
Kelurahan tidak muncul setelah pilih Kecamatan Refresh halaman. Jika masih kosong, hubungi admin — data kelurahan mungkin belum diinput.
Import CSV gagal / error Periksa format kolom menggunakan template. Pastikan tidak ada kolom kosong yang wajib diisi.
Tombol Export Agregat abu-abu Pilih Bulan dan Tahun terlebih dahulu di bagian Export Agregat.
Peta tidak muncul di form Tambah Kasus Pastikan koneksi internet aktif. Peta memerlukan koneksi untuk memuat tile map.
Z-Score tidak terhitung Pastikan data referensi WHO (tabel Z-Score) sudah terisi di database. Hubungi Super Admin.
Halaman loading lambat Gunakan filter untuk mempersempit data. Hindari menampilkan semua data tanpa filter pada dataset besar.
