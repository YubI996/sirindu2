# Import Nama PJ (alokasi otomatis per wilayah) + Rename Menu "Operasi Timbang" — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dinkes mengunggah CSV `kelurahan, posyandu, nama_pj`; sistem membagi rata anak yang saat ini stunting/wasting/underweight di tiap wilayah ke PJ yang terdaftar (round-robin), tanpa menimpa PJ yang sudah ada kecuali diminta; hasil tetap bisa diubah di modal dasbor OT. Menu "Gizi & Timbang" berganti nama "Operasi Timbang".

**Architecture:** Aturan "anak bermasalah gizi menurut kunjungan OT terakhir" diekstrak dari `TimbangDashboardController` ke `OtGiziService` (controller mendelegasikan — tanpa perubahan perilaku, dikunci tes OT yang ada). `PjAlokasiService` memakai service itu untuk alokasi. Import mengikuti pola modul Import CSV: `ImportLog` jenis `pj`, `ImportPjJob` (antrean), template, tab di halaman import.

**Tech Stack:** Laravel 12, PHP 8.4, `fgetcsv` (tanpa Maatwebsite — CSV kecil), PHPUnit 11.

**Spec:** keputusan klien 15 Sep 2026 (percakapan): CSV per wilayah dibagi rata; anak yang sudah punya PJ dilewati kecuali "timpa"; kategori PJ = stunting|wasting|underweight (`TimbangDashboardController::KATEGORI_PJ`).

```php
    public function filterKosong(array $override = []): array
    {
        return array_merge(['tahun' => null, 'kec' => null, 'kel' => null, 'rt' => null, 'posyandu' => null], $override);
    }

    /** @return array<int, array{g:array, tgl:string}> */
    public function klasifikasiTerakhir(array $f): array
    {
        $rows = DB::table('data_anak as da')
            ->join('anak as a', 'da.id_anak', '=', 'a.id')
            ->whereIn('da.id', $this->latestVisitQuery($f))
            ->select('da.id_anak', 'da.bb', 'da.tb', 'da.bln', 'da.tgl_kunjungan', 'da.zscore_bb_u', 'da.zscore_pb_u', 'da.zscore_bb_pb')
            ->get();
        $out = [];
        foreach ($rows as $m) {
            if ($m->bln > 60 || $m->bb <= 0 || $m->tb <= 0) continue;
            $out[(int) $m->id_anak] = [
                'g'   => $this->statusGizi->enumEppgbm($this->zval($m->zscore_bb_u), $this->zval($m->zscore_pb_u), $this->zval($m->zscore_bb_pb)),
                'tgl' => $m->tgl_kunjungan,
            ];
        }
        return $out;
    }

    public static function kena(array $g, string $kategori): bool
    {
        return match ($kategori) {
            'stunting'    => in_array($g['tb_u'], ['severely_stunted', 'stunted'], true),
            'underweight' => in_array($g['bb_u'], ['severely_underweight', 'underweight'], true),
            'wasting'     => in_array($g['bb_tb'], ['wasted', 'severely_wasted'], true),
            'gizi_kurang' => $g['bb_tb'] === 'wasted',
            'gizi_buruk'  => $g['bb_tb'] === 'severely_wasted',
            default       => false,
        };
    }

    public function idAnakMasalahGizi(array $f, array $kategori): array
    {
        $ids = [];
        foreach ($this->klasifikasiTerakhir($f) as $id => $k) {
            foreach ($kategori as $kat) {
                if (self::kena($k['g'], $kat)) { $ids[] = $id; break; }
            }
        }
        return $ids;
    }
```
